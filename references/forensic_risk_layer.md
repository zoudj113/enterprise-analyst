# 舞弊取证增强层（Forensic Layer）

> 配套 `SKILL.md` 第七步。本文件补足 `risk_checklist.md` 未覆盖的**取证型**检查：
> **第 0 层硬伤否决 → 利润来源定性 → 现金流交叉验证 → 勾稽校验**。
>
> 借鉴自第三方财报排雷方法论，但**只取其取证逻辑，不取其评分体系**——
> 本技能的目标是"判断企业质地"，不是"给公司判刑"，加权打分会让结论显得比实际更可靠。

---

## 一、第 0 层：硬伤一票否决（第七步前置，必做）

**执行位置**：在做任何比率分析**之前**。理由很简单——如果审计师已经出具非标意见，后面所有比率的可靠性都不存在。

**逐条核验并写进报告**（即使全部无异常，也要写"已核验，无非标"）；
⚠️ **不得凭印象写"无异常"**——上一版中烟香港报告里出现过"无审计保留意见"的表述，
当时并未真正查阅，属于**虚假陈述**。必须回原文核实后才写。

| # | 硬伤项 | 判定阈值 | 去哪找 |
|---|---|---|---|
| 1 | **审计意见类型** | 非标准无保留意见（保留/无法表示意见/否定意见）→ 一票否决 | 年报「独立核数师报告」首段 |
| 2 | **关键审计事项（KAM）** | 存在即列出并复述；涉及收入确认/存货/商誉减值的 KAM 是排雷高价值线索 | 核数师报告「关键核数事项」章节 |
| 3 | **会计师事务所变更** | 报告期内更换审计师，或连续经营期内频繁变更 → 🔴 | 年报「企业管治」/董事会报告 + 公告检索 |
| 4 | **控股股东股权质押** | 控股股东质押比例 **>50%** → 🔴（股价下跌触发平仓风险） | 年报「主要股东」附注 + 披露易权益披露 |
| 5 | **监管问询 / 做空报告** | 交易所问询函、SEC 问询、知名做空机构报告、集体诉讼 | 监管网站 + 公开检索（须注明来源） |
| 6 | **推迟刊发业绩 / 补充更正公告** | 出现即 🔴 | 公司公告 |
| 7 | **内部人大额减持** | 董监高/大股东报告期净减持显著 | 权益披露（港股 SDI、美股 Form 4、A股大宗+减持公告） |
| 8 | **海外业务 / 离岸主体畸高** | 收入或资产高度集中于无实质经营的离岸实体且无商业理由 | 附注「附属公司名单」+分部地区资料 |

**输出方式**：在风险章节开头放一张小表（硬伤项 | 结论 | 依据），全部无异常时压缩为一句话
"（第 0 层硬伤核验：8 项全部无触发，审计意见为标准无保留。）"，不要占用整章篇幅。

**触发否决时的处理**：第 1 项（非标审计意见）命中时，其余章节照常分析，但必须在
「核心速览」顶部加一条醒目提示，并在总结里写明"因审计非标，本报告所有财务推断的可靠性基础不成立"。

### 两项补充核验（同样属于第 0 层，易被忽略）

**A. 核数师薪酬结构**——查「核數師薪酬」附注，看非审计服务费用 ÷ 审计服务费用。
持续超过 50% 说明独立性可能受损（审计师靠非审计业务赚钱，有动机不与客户撕破脸）。
报告中写清两个绝对额与比值即可。

**B. 慎防把「协定程序（AUP）」当成背书**——⚠️ **这是最容易踩的坑**。
部分公司会额外聘请核数师做《香港相关服务准则》第 4400 号（或等效准则）下的**协定程序**，
例如把本公司周转天数、利润率与可比公司做比对，得出"均在可比公司范围内"的结论。
必须记住三条：

1. **AUP 只陈述执行的事实结果，不提供任何鉴证保证**，与"核数师已证明定价公允"完全是两回事；
2. 可比公司往往由**董事会自行选择**，且"落在范围内"是极宽的标准，信息量有限；
3. 公司愿意专门花钱做这类比对，**恰恰说明关联交易定价公允性是它最在意也最脆弱的地方**——
   这是线索，不是免罪证明。

报告引用时必须写明"该结论属协定程序、不构成鉴证"，且**不得**用来减免关联交易风险等级。

## 二、利润结构四分法（定性利润从哪来）

`risk_checklist.md` 第 4 项只算了"非经营利润占比"，**没有给利润来源做定性**。补上四分法：

```
核心利润 = 营业收入 − 营业成本 − 税金及附加 − 销售/管理/研发费用 − 利息费用 + 利息收入（经营性部分）
         ≈ 毛利 − 四费 （本技能用的简化口径，须在报告中注明口径）
```

按四类占**利润总额**的比重定性：

| 类型 | 判定条件 | 定性表述 |
|---|---|---|
| **干出来的** | 核心利润 ≥ 80% | 利润来自主业经营，质量最高 |
| **补出来的** | 其他收益/政府补助/营业外 > 20% 且核心利润 < 60% | 靠补贴与一次性收益补，**含金量存疑** |
| **投出来的** | 投资收益 + 公允价值变动 > 40% | 主业赚不过投资，实质是控股/投资平台 |
| **洗出来的** | 资产减值损失占毛利 > 20%（巨额负向计提） | 当期"洗大澡"，需还原看真实经营数 |

**必须写明的两个衍生判断**

1. **净利润与核心利润背离**：若核心利润为正但净利润为负，或反之，必须解释差额来源。
2. **可持续性测试**：把非经常性项目剔除后，**连续看图**（至少 3 期），看核心利润是趋势上升还是靠某一年的一次性收益撑起。

> **中烟香港实例（2026H1，已核验）**：核心利润 = 毛利 856,321 − 行政及其他经营开支 82,937 = **773,384 千港元**，
> 占税前利润 789,633 千港元的 **97.9%**；非经营净额 = 其他收入净额 96,383 − 融资成本 80,134 = **+16,249（+2.1%）**。
> 跨期验证：2025H1 为 101.3%、2025 全年 101.5%、2024 全年 109.3%——**连续四期均为「干出来的」**。
>
> ⚠️ **注意别踩这个坑**：单看"其他收入净额占税前利润 12.2%"（其中利息收入单项 9.8%）很容易误判为"高依赖非经营"，
> 但**利息收入与融资成本同属非经营项、必须相互抵消后再看**——毛口径会显著夸大依赖度。
> 本例曾据此把该项误列为高风险，经复核后应**下调为"中"**，保留关注的原因是波动性（汇兑摆动 2,763 万，占税前利润 3.5%）
> 与闲置资金效率，而非"利润注水"。这正是判读三步要求"列全成因、比对方向"的价值。

## 三、现金流交叉验证（三个指标，补足单一比率的不足）

`risk_checklist.md` 只用了一个「经营现金流 / 净利润」。补三个更有解释力的：

### 3.1 核心利润获现率

```
核心利润获现率 = 经营活动现金流净额 ÷ 核心利润
```

- **> 100%** → 利润充分变现，还预收了钱（优质）
- 70%–100% → 基本健康
- **< 70%** → 🟡 利润有"白条"成分
- **连续 2 年 < 50%** → 🔴 利润可能有水分

> 比「OCF/净利润」更严格：分母剔除了投资/处置等非经营项，直接衡量主业赚钱能否变成现金。

### 3.2 销售收现比

```
销售收现比 = 销售商品/提供劳务收到的现金 ÷ 营业收入
```

**基准取值（市场差异，勿混用）**：

| 市场 | 基准 | 说明 |
|---|---:|---|
| **A 股** | **1.13** | 含 13% 增值税，现金口径含销项税 |
| **港股 / 美股** | **1.0** | 无增值税，不可套用 1.13 基准 |
| 有大量票据结算 / 背书的制造业 A 股 | 会显著低于 1.13 | 需查"应收票据"与背书贴现附注后再判 |

- 明显低于基准 → 收入里可能有未收现部分 ➕ 应收在膨胀，需回看应收账款科目
- **必须先用准则判定市场，再选基准**——这一步错，整条结论都错。

### 3.3 现金流量肖像八型

按 `CFO / CFI / CFF` 三者正负号组合给企业"画像"，一句话说清它现在处于哪个生命阶段：

| CFO | CFI | CFF | 类型 | 含义 |
|:---:|:---:|:---:|---|---|
| + | + | − | **老母鸡型** | 成熟期现金牛，经营造血、收缩投资、还钱分红——最优 |
| + | − | − | **奶牛型** | 经营造血，同时扩张并回报股东——健康成长期 |
| + | − | + | **蛮牛型** | 经营造血但借债扩张，激进但可控 |
| − | − | + | **赌徒型** | 经营失血仍举债扩张，高风险 |
| − | + | − | **大出血型** | 经营失血、变卖资产还债，困境反转或垂死挣扎 |
| − | − | − | **混吃等死型** | 全面收缩消耗存量现金 |
| + | + | + | **妖精型** | 经营赚钱、还在变卖家当、还在借钱——钱去哪了？需重点核查 |
| − | + | + | **骗吃骗喝型** | 经营不赚钱靠输血，红色警报 |

**必做跨期漂移跟踪**：算出最近 3 期的肖像并记录漂移路径。
例如「奶牛 → 蛮牛 → 赌徒」是**商业模式质变的早期信号**，比任何单一比率都更早亮灯。

**⚠️ 判定前必须先做「定存还原」**：现金流量表里的**投资活动**经常混入"存放/赎回原到期日超过三个月的
短期银行存款"，那**不是投资，是现金管理**（从左口袋挪到右口袋）。不还原会把肖像误判为"在扩张"。

做法：从 CFI 各明细行中剔除存款类流入/流出，再看剩余部分（真实资本开支与处置收益）的正负。
例：某公司 2026H1 CFI 净流出 2.97 亿，其中存放定存 3.37 亿、购置固定资产仅 88.9 万、已收利息 4,063 万
——还原后 CFI 实为**净流入** 3,974 万，肖像由「奶牛型 (+,−,−)」变为「老母鸡型 (+,+,−)」，
**"几乎不投资"这个事实比任何表述都更能说明其扩张承诺的成色**。

## 四、勾稽五闸（数据纯净性自检 —— 在下结论之前过一遍）

1. **勾稽校验**：分部收入加总 = 总收入（允许 ±0.1 尾差）；净利润 ÷ 每股盈利 ≈ 加权平均股数；
   资产 = 负债 + 权益。**三者任一不平，报告须说明尾差来源**，不能闷声掲过。
2. **区分"未披露"与"不存在"**：某科目表内没有，必须回原文确认是未披露还是该项为零/不适用——
   尤其在港股（披露粒度粗于 A 股），缺项一律写"因披露粒度无法深入分析"，**不得标记为财务疑点**。
3. **数值恰好等于阈值**：不要直接判 PASS/FAIL，回源再核一次是否口径凑巧。
4. **关键数字双源核对**：营收/净利/经营现金流三巨头至少两个独立来源；
   仅单源时显式标注 `⚠️ 单源数据，未经双源核对`。
5. **降级源 ≠ 降级标准**：数据源换成二手转载时，核验阈值**不得同步放松**。

## 五、判读纪律：规则输出是「信号」不是「判决」

⚠️ **这是本文件最重要的一条**，适用于上面所有公式与阈值，也适用于 `risk_checklist.md` 的 10 项必查。

任何比率触发红灯后，**必须走完判读三步才能写进结论**：

1. 这个公式测的是**哪个维度**的偏离？
2. 造成该偏离的成因**有几种**（至少列出正反两种）？
3. **成因方向是否与定罪特征一致**？不一致 → 降级为"关注项"，并写明降级理由 + 下期必查项。

> **反面案例**（第三方技能自己踩过的坑）：某标的"归母/合并利润偏离度连续四期 >100%"被脚本判 FAIL，
> 深究成因是**少数股东权益为负**（子公司亏损由少数股东分担），与"体外藏亏"的定罪特征（少数股东权益为正而利润被分流）
> **方向完全相反** → 正确处置是降级为关注项，同时把"境外子公司减亏进度"列为下期必查，而不是给公司定罪。

**配套原则：「无法排除嫌疑 ≠ 确认造假」**——数据不足以排除风险时，标记
`⚠️ 无法排除嫌疑`，**不得**为了报告好看而写成 PASS（制造虚假安全感），也不得因为看不懂就写成造假。

## 六、常见误判补充（与 risk_checklist.md 第六节合并使用）

| # | 误判 | 正确做法 |
|---|---|---|
| 7 | 白酒/名酒存货激增 = 积压 | 基酒陈酿是主动价值创造。区分"生产型存货增加"与"滞销型积压"，查产销量匹配度 |
| 8 | 跨国巨头存贷双高 = 造假 | 海外现金 + 境内发债回购是合法税务筹划。查**利息收支匹配度**，不能只看余额 |
| 9 | 品牌溢价 = 毛利率异常 | 品牌壁垒型天然高于代工型同行。同行对比须排除商业模式不同的公司 |
| 10 | 经营现金流为负 = 利润有水分 | 区分"成长型负现金流"（高速扩张/重资产投入期）与"衰退型负现金流" |
| 11 | 一刀切套用全部检查项 | **先判定企业类型**（周期股/成长股/金融股/平台型），再选择性激活 |
| 12 | 只看财务不看非财务 | 舞弊公司的**非财务异常出现频率约为财务异常的 3.7 倍**（治理/业务信号更早亮灯） |

**非财务信号八问**（每次都必须扫，尽管多数时候无发现）：
商业模式 · 行业位置 · 竞争壁垒 · 客户结构 · 供应商依赖 · 管理层 · 治理结构 ·
外部信号（监管问询/做空报告/媒体质疑/大股东减持）。
