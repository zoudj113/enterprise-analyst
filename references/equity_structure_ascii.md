# 股权架构图模板 · 纯文本版（ASCII Art）

当 Mermaid 在某些 Markdown 渲染器中无法正常显示时（如 markdown-it-mermaid 报错、SVG 兼容性差），可使用纯文本 ASCII Art 绘制股权架构图，**保证任何渲染器都能正确显示**。

## 模板

```
紧接H股发行前·股权及公司架构（招股说明书原始图示复刻）

                          [实控人]

                  │ 直接持有      │             │
                  │ [A]%         │             │
                  │ 持有 [B]%    │             │
                  ▼              │             │
            [控股平台]            │             │
        [控股平台全称]            │             │
                  │ 持有 [C]%    │             │
                  ▼              ▼             │
              ┌─────────────────────────────────┐
              │        控制合计约 [D]%          │
              └─────────────────────────────────┘
                              │
                其他股东 [E]%（含 [F] 库存股份）
                              │
                              ▼
                  [上市公司全称]
                （注册资本：[G]元）
                              │
       ┌──────┬──────┬────────┴────────┬──────┬──────┐
     100%   100%    100%              100%   100%
   [子1]  [子2]   [子3]            [子4]    [子5]
   （境内）（境内）（中国香港）    （泰国）  （德国）
                                            │

(4) 其他子公司包括：[详细列表]。
```

## 绘制规范

1. **三层结构**：实控人 → 上市公司 → 子公司
2. **对齐**：使用空格手动对齐，建议固定宽度节点如 `[潮州三环（集团）股份有限公司]`
3. **连接符**：
   - 上下层级用 `│` 和 `▼` 垂直连接
   - 平行分支用 `┌┐└┘─┘` 水平连接
   - 100% 全资用粗连接（如 `┴`），部分持股标注百分比
4. **控股方框**：用 `┌─┐` 和 `└─┘` 包裹强调（如"控制合计"）
5. **注脚**：在图下方用 `(1)(2)(3)(4)` 编号 + 列表说明复杂股权关系
6. **不要加颜色**：纯文本版追求最大兼容性，颜色用文字标注（如"紫色=控股股东"）

## 优势 vs 劣势

| 维度 | Mermaid 版 | 纯文本版 |
|------|-----------|---------|
| 渲染兼容性 | ⚠️ 部分渲染器失败 | ✅ 100% 兼容 |
| 美观度 | ✅ 图形化 + 颜色 | ⚠️ 纯文本 |
| 信息密度 | 🟡 中等 | ✅ 高 |
| 复制编辑 | ⚠️ 需懂 Mermaid 语法 | ✅ 任意编辑器 |
| 适合场景 | 演示、报告展示 | 通用文档、技术文档 |
