# 定性结论与用词纪律（机械可查）

> **约束对象**：报告里**没有数字的那些句子**——护城河、竞争格局、生意质量、行业地位、管理层。
> 数字有出处（一手财报），定性句最容易失守：写得越顺、越像常识，越可能是没根据的。
>
> **规则源**：`scripts/check_report.py` 的 **[12] 绝对化词扫描** 与 **[13] 定性结论出处标注**。
> 本文件是这两项检查的**操作化展开**（怎么写就过检），不新增规则；与 `SKILL.md` 冲突时以 SKILL.md 为准。
>
> **来源**：借鉴自 `investor-framework`（价值投资框架镜像）的「定性结论出处纪律」，
> 2026-09-22 落地。该框架的原始教训见第二节。

---

## 一、为什么单列一层

第 0 层硬伤、三层风险扫描管的是**数字**（审计意见、勾稽、比率、背离度）。
但报告真正被读者记住的往往是定性句——「护城河宽阔」「最大威胁是代际迁移」「管理层资本配置能力强」。
这些句子：

- 没有数字可核对，**自检脚本查不到**；
- 写起来最省事，因此**最容易被套话填充**；
- 一旦写错，整份报告的结论方向就偏了（比一个数字抄错更严重）。

所以单列一层纪律，并做成**机械可查**的检查项。

---

## 二、原始实盘教训（农夫山泉案，来自该框架记录）

| 写进报告的定性 | 真相 | 病因 |
|---|---|---|
| 「全国冷链」 | grep 招股书**零命中**，公司从未这样披露 | 无一手源却当事实反复写 |
| 「茶饮料 No.1」 | 2019 年实为**第 3**，且无当前年份的来源 | 陈旧信息当现状 |
| 「不可复制」 | overreach，无数证据支撑 | 绝对化词代替论证 |

三个病根是同一个：**搬运旧稿措辞 + 不追来源 + 吸收卖方自夸**。

> 对本技能的映射：刷新同一家公司的报告（或复用旧报告的段落）时，
> **旧稿的定性句一律当"门面"处理，回原文重验，不继承旧措辞**。

## 三、四分法：每句定性必须可归类

写完报告，**逐句**问一句「这句话的出处是哪类」。归不进去 = 违规。

| 标记 | 含义 | 合格标准 |
|---|---|---|
| **【源】** | 一手财报 / 招股书 / 公告原文 | **可引到具体位置**（章节 / 附注 / 页码）。写「【源】」不写位置 = 不合格 |
| **【推】** | 从报告里**已列出的事实**推断 | 须能指回上文哪个数字或哪张表 |
| **【判】** | 分析者的定性判断 | 须**同时列出依据**（≥2 条事实），否则是主观感受 |
| **【疑】** | 听来的 / 门面的 / 未核实 | 核完再用。确实无法核实的，标注「未核实」并说明影响 |
| **【公司自述】** | 招股书 / 年报 MD&A 里的自我评价 | **必须打折**（见第四节），且不得单独支撑护城河结论 |

**在报告中怎么用**：不必每句都挂标记（那会很啰嗦），但**每处关键定性结论**（护城河段落、
行业地位段落的竞争判断、风险章的成因方向）应当挂上，让读者知道这句的成色。

**自检要求**：全文 **≥3 处**出处标记（脚本 [13] 检查）。低于 3 处说明定性结论基本没标出处。

## 四、卖方自夸必须打折

招股书和年报 MD&A 里的「竞争优势」「行业领先」「长期稳定增长」「护城河深厚」——

**这是营销材料，不是独立事实。** 它只证明公司自己这么认为。

处理方式（二选一，不能都不做）：

1. 找到**独立佐证**（第三方市占数据、同业财务横比、监管文件、客户/供应商公开信息）→ 可作结论 →
   写「…（【源】FY2025 10-K + 第三方 XX 数据交叉验证）」
2. 找不到独立佐证 → 标 **【公司自述】** 并明说「未独立验证」

> ⚠️ 最危险的写法是**把公司自述改写成自己的判断**（去掉"公司称"三个字）。
> 那会让读者以为是你核实过的——这是虚假陈述，比抄错数字严重。

## 五、绝对化词 ban-list（脚本 [12] 机械扫描）

### 硬档：出现即 FAIL（在财务分析语境下没有正当用途）

```
不可复制　不可撼动　完美　无可挑剔　极致　极佳　必然　永远
No.1　NO.1　零风险　稳赚　绝对领先　无可比拟　独一无二　100%确定
```

**为什么这些是硬档**：财务分析的基本前提是「未来不可预测、优势会被侵蚀」。
这些词的语义是「不会变坏 / 已被证明完美」，与前提矛盾，等于用措辞替代论证。

### 软档：命中后检查**同行内是否有数字或出处标记**

```
唯一　垄断　龙头　领先地位　绝对优势　绝对领先
全球第一　行业第一　全国第一　排名第一　世界第一
最强　最优　最佳　最先进　最具　霸主　王者　天花板
```

> **词表只收高置信营销词组**。单字与泛词（`最` / `全部` / `第一` / `领先` / `最大`）已剔除——
> 实测误报过多：「绝对值」「第一问」「第一梯队」「影响最大」都是正常表述。
> 例外的**法律/股权语境**也自动豁免（正则 `唯一(的)?(控制人|股东|持有人|表决权|投票权|真源|法定)`），
> 因为「Class B 股的唯一控制人」是事实描述而非营销。

**豁免规则（脚本自动判定）**：命中行的**同一行内**出现
- 数字（`0-9`），或
- 出处标记（`【源】/【推】/【判】/【公司自述】`）

→ **豁免**（视为有实证的表述）；两者都没有 → 🟡 WARN，提示补数字或出处。

| 写法 | 判定 | 说明 |
|---|---|---|
| `市占率 26.8%，全球第一` | ✅ 豁免 | 同行有数字 |
| `茅台是白酒行业唯一具备地理壁垒的企业【源】FY2025 年报 P12` | ✅ 豁免 | 同行有出处标记 |
| `Mark Zuckerberg 是 Class B 股的唯一控制人` | ✅ 豁免 | 法律/股权语境（事实描述） |
| `技术领先，壁垒深厚` | 🟡 WARN | 无数字无出处 = 套话 |
| `管理层非常优秀` | 🟡 WARN | 应改为「【判】依据：近 5 年 ROE 23–31%、分红率 40%…」 |

> **软档不是禁用，是「要有代价地使用」**：带上数字或出处，这些词就能用。
> 硬档没有豁免路径——想表达那个意思，就拆成可验证的句子。

## 七、刷新时的搬运禁忌

刷新同一家公司的报告（新一期财报、或复用旧稿段落）时：

1. **旧稿定性句一律视为未验证**——包括你自己上一版写的（"同项目上一版也是门面"）。
2. 逐句回源：能重新验证的标【源】，验不了但仍有价值的降级标【疑】。
3. 数字全部重取（见 `references/pre_write_checklist.md` 的序列校验要求），不复用旧表的数字。
4. 旧稿引用过的外部数据（市占率、批价、研报观点）**必须核对时点**，过期的标注年份或删除。

## 八、专业术语首次出现必须给原文定义（2026-09-23 实盘教训，Amazon 案）

**问题**：Amazon 报告里写了「非现金、非经营、且属 **Level 3 主观估值**」。用户追问「这是什么意思、
你从哪里找来的」——说明这个压缩标签**没让读者看懂，反而引起了对依据的怀疑**。

**核查结论：依据站得住，但表述压缩过度。**

- 「Level 3」是财报原文用词，不是自造：Amazon 自己把 Anthropic 可转债标为 *"classified as
  available-for-sale ... and as **Level 3** assets"*，非投票优先股与 OpenAI Series C 亦然。
- 但「**主观估值**」是我们自己压出来的中文标签，容易被读成「凭空估值」——而财报原文写的是该上调
  反映 *"**observable changes in price** related to Anthropic's fundings"*，即**锚定新一轮融资定价**，
  有客观参照；归入第三层级的原因是**无公开市场报价**且需扣不可流通折价（DLOM）。

**规则（适用于所有会计/金融专业术语）**：

1. 术语**第一次出现处**必须做到三件事，缺一不可：
   ① 引**原文英文原句**并附中文直译；② 给出该层的**判定条件**（如"输入不可观察"）；③ 说明它在本案中
   **为什么适用**、以及对结论**意味着什么**。
2. **禁止只留压缩后的中文标签**。压缩标签（如"主观估值""轻资产""表外"）是给内行看的速记，
   写在报告里会同时得罪内行（不精确）和外行（看不懂）。
3. **警惕"术语自带的褒贬色彩"**。「主观」在中文语境含贬义，而 Level 3 是一个**中性的会计计量分类**，
   不含"造假"含义。选词时必须把术语的**中性属性**讲明，否则等于在暗示造假——这是严重的定性越界。
4. 只要写了「非现金 / 非经营 / 需重大判断」这类限定语，就必须**同时写清它仍有的客观锚点**，
   否则读者无法判断这个数字该信几分。
5. 推荐做法：**会计 / 审计 / 估值术语在首次出现处用一句话就地解释**（括号带出英文全称 + 中文直译），
   不再集中进「术语注解」表。
   ⚠️ **2026-09-24 用户定稿**：术语注解表**只收行业专有名词（原料 / 工艺 / 产品形态）**，
   会计术语一律移出、改为就地解释。原因：集中列表会随公司复杂度膨胀（农夫山泉实测 20 → 2 条），
   而读者只在自己读到该词时才卡住，就地解释既不占篇幅又恰逢其时。
   移出时注意 `[14]` 仍要求 `KAM / 关键审计事项 / 净现金转换周期` 等词有定义式说明，
   必须把定义搬到正文首现处（详见 `references/pre_write_checklist.md` 的 [14] 小节「就地解释操作要点」）。

**同类高风险术语清单**（出现时照此办理）：Level 1/2/3 公允价值层级、VIE、商誉减值测试、
递延所得税资产确认、股份支付费用、使用权资产、可变利益实体、非控制性权益、KAM（关键审计事项）。

> **本节已有脚本检查项**（2026-09-23 落地）：`check_report.py` 的
> **`[14]` 高风险术语是否给出定义**（FAIL 级）+ **`[15]` 英文缩写首现展开**（提示级）。
> 脚本认可的三种定义式写法见 `references/pre_write_checklist.md` 的 [14] 小节。
> 但 watchlist 只覆盖高危子集，**其余术语仍属人工纪律**：
> 凡是报告里出现了英文缩写或会计专有名词，回到它第一次出现的位置，确认旁边有一句
> 「它是什么 + 原文怎么说 + 本案为什么适用」。
