# 产品用途与下游客户映射（企业概况章节必备）

## 为什么必须有这一节

财报里的「主营业务 / 主要产品」通常是**名词罗列**：

> 主要产品：氧化铝、铝用阳极炭素、石墨化阴极、重熔用铝锭、精铝锭、圆/扁铸锭、
> 铸造铝合金锭、电工圆铝杆、铝及铝合金焊材

读者看完只知道公司名字里有哪些词，**不知道这些产品到底是什么东西、在工业里干什么用、
最后被谁买走**。这直接导致后面所有分析失去锚点——看不懂产品，就看不懂它的周期属性、
议价能力、客户集中度从何而来。

**因此：企业概况（第一章）必须有一张「产品 → 用途 → 客户」映射表，把名词翻译成生意。**

## 五要素表头（固定）

| 产品 | 是什么（形态 / 规格 / 牌号） | 工业用途（在产业链里干什么） | 直接客户（谁买走、买去做啥） | 终端行业 |
|---|---|---|---|---|

五列一个都不能少。常见错误是只写前两列（产品 + 是什么），那仍然没有信息量。

### 各列怎么写

**① 是什么**：物理形态、典型规格、行业牌号。让外行能想象出实物。
- 例：重熔用铝锭 —— 电解槽产出的液态铝浇铸成的标准锭，牌号 Al99.70（俗称 A00 铝），
  上期所沪铝期货的标准交割品
- 例：电工圆铝杆 —— φ9.5mm / φ12mm 的铝杆盘条，牌号 A2/A4/A6

**② 工业用途**：它在下游生产流程中**扮演什么角色**，是原料、耗材、半成品还是成品。
- **原料型**（被消耗、变成别的东西）：氧化铝是电解铝的原料，1 吨原铝约耗 1.92 吨氧化铝
- **耗材型**（生产过程中被消耗掉）：预焙阳极是电解槽的阳极，参与电化学反应被消耗，
  1 吨铝约耗 0.5 吨
- **设备/内衬型**：石墨化阴极是电解槽底部的导电内衬，属于固定资产性质的耐材
- **半成品型**（还要再加工）：圆铸锭/扁铸锭是铝合金熔铸后的中间坯料
- **成品型**（可直接交付终端）：电工圆铝杆、焊材

**③ 直接客户**：采购方是谁（行业 + 企业类型），**以及它买去做什么**。
- 中间品大量**内部自用**时必须写明比例或定性（"主要配套自有电解铝产能，少量外售"）——
  这是判断一体化程度与真实外销规模的关键，漏写会高估收入
- 客户名**只能引用年报披露**（「前五名客户」、关联交易对手方）；
  年报未披露时写"公司未披露具体客户名称"，**严禁编造具体公司名**

**④ 终端行业**：产品最终流向哪些终端领域（建筑、汽车、电力、包装、3C、光伏……）。
这一列决定公司的**周期属性**——终端是基建地产、还是新能源、还是消费，估值逻辑完全不同。

## 撰写纪律（硬性）

1. **禁止名词罗列**。每个产品必须回答"干什么用 + 卖给谁"，否则等于没写。
2. **区分内部自用与外销**。垂直一体化公司（矿→冶炼→加工）的中间品大部分自用，
   不写清会让读者误以为那部分产能都是外销收入。
3. **客户分层**：直接客户 ≠ 终端行业，两列都要写。
   （例：电工圆铝杆的直接客户是电缆厂，终端行业是电力输配电）
4. **来源可追溯**：
   - 客户集中度数字 → 年报「前五名客户销售额占比」
   - 客户名称 → 年报披露的关联方 / 前五大客户
   - 产品用途与工艺常识 → 属**行业通识**，在表下注明"（产品用途与工艺口径为行业通识，
     非公司披露）"，与公司一手数据区分开
5. **不得编造**：年报没写客户名就写"未披露"；用途不确定就写行业惯例并标注，
   严禁把猜测写成事实。
6. **与后文呼应**：这张表是后面「集中度风险」「关联交易」「周期属性」的判断基础——
   若某终端行业占比畸高，风险章节必须引用本表结论，不能各说各话。

## 完整示例：电解铝企业（云铝股份口径）

| 产品 | 是什么 | 工业用途 | 直接客户（买去做啥） | 终端行业 |
|---|---|---|---|---|
| 氧化铝 | 白色粉末，铝土矿经拜耳法提炼，分冶金级/非冶金级 | 电解铝的**原料**，约 95% 的氧化铝用于电解产原铝（1 吨铝耗约 1.92 吨） | **主要配套自有电解铝产能自用**；少量外售其他电解铝厂，非冶金级另售陶瓷、耐火材料、催化剂、磨料行业 | 有色金属冶炼（自用）；陶瓷/耐火材料 |
| 铝用阳极炭素（预焙阳极） | 石油焦 + 煤沥青制成的炭块，电解槽阳极 | 电解过程中**导电并参与电化学反应，被持续消耗**（1 吨铝耗约 0.5 吨） | 电解铝厂——云铝自身产能为主，外售部分供给其他铝厂 | 有色金属冶炼 |
| 石墨化阴极 | 经高温石墨化处理的阴极炭块，电解槽内衬 | 电解槽**底部的导电内衬**，耐高温、抗钠侵蚀，降低槽电压、延长槽寿命；用于新建与大修 | 电解铝厂（新建/技改/大修） | 有色金属冶炼 |
| 重熔用铝锭（原铝） | 电解铝液浇铸的标准锭，牌号 Al99.70（A00 铝），上期所沪铝**标准交割品** | 大宗标准商品，下游**重熔后加工**成各类铝材；也用于期货交割 | 铝加工厂、压铸厂、贸易商；部分通过集团销售平台/贸易渠道走货 | 建筑、交通运输、电力电子、包装、耐用消费品 |
| 重熔用精铝锭 | 原铝经三层液电解或偏析法提纯，纯度 99.95%–99.99% | 高纯铝，用于**电子铝箔、电容器、溅射靶材**等对纯度敏感的场景 | 电子铝箔厂、电容器厂、高纯材料厂 | 电子元器件、化工设备、照明 |
| 变形铝及铝合金圆铸锭 / 扁铸锭 | 铝合金熔铸后的**中间坯料**：圆锭（圆棒）、扁锭（板坯） | **半成品**，再加工用：圆锭→挤压成型材/管棒；扁锭→热轧成板带箔 | 铝挤压厂、铝板带箔轧制厂 | 建筑型材、光伏边框、汽车、3C、罐料 |
| 铸造铝合金锭 | 适配铸造工艺的合金锭（如 ADC12、A356 系列） | **压铸/重力铸造的原料**，直接熔化后浇铸成零件 | 压铸厂、铸造厂 | 汽车（缸体、变速箱壳、车轮、电机壳、一体化压铸结构件）、通信基站壳体 |
| 电工圆铝杆 | φ9.5/φ12mm 铝杆盘条，牌号 A2/A4/A6 | **拉丝制成电线电缆导体**（导电率与强度平衡） | 电线电缆厂 | 电力输配电（钢芯铝绞线）、变压器绕组、电机 |
| 铝及铝合金焊材 | 焊丝/焊条（如 ER4043、ER5356 系列） | 铝合金结构的**焊接填充材料** | 焊接施工单位、造船/轨交/压力容器制造商 | 船舶、轨道交通、压力容器、铝合金结构工程 |
| 再生铝 | 废铝回收熔炼后的铝液/铝锭 | 替代原铝，降低能耗与碳排（再生铝能耗约为原铝的 5%） | 同铝锭客户：压铸厂、铝加工厂 | 汽车、包装、建筑 |

> 表下注明：产品用途、工艺与行业流向为**行业通识**；客户与销售口径来自年报「营业收入构成」
> 「前五名客户」「关联交易」等披露项；未披露客户名称的，不作推测。

## 常见错误

| 错误写法 | 问题 | 正确做法 |
|---|---|---|
| "主要产品：氧化铝、阳极炭素、铝锭……" | 纯名词罗列，零信息量 | 逐项展开五要素 |
| "铝锭用于工业生产" | 等于没说 | 写明"下游重熔后加工成铝材，直接客户是铝加工厂/压铸厂" |
| 把氧化铝、阳极炭素全算作外销收入 | 忽略内部自用，高估收入与毛利率 | 明确标注"主要配套自有产能自用" |
| "客户包括某某集团、某某汽车"（年报未披露） | 编造 | 写"公司未披露具体客户名称"，改用行业口径 |
| 只写终端行业不写直接客户 | 看不出议价链条 | 两层都写 |
